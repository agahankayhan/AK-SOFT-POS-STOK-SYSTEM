Başlangıç Adımları

  1. Yukarıdaki linkten AKSOFT_STOK_v20.exe dosyasını indirin.
  2. İndirilen dosyaya çift tıklayın.
  3. Windows Defender uyarısı çıkarsa "Daha fazla bilgi" -> "Yine de çalıştır" seçin.
  4. Aşağıdaki varsayılan bilgilerle giriş yapın:
Kullanıcı Adı : admin
Şifre : admin123

Güvenliğiniz için ilk girişten sonra şifrenizi Ayarlar bölümünden değiştiriniz.

Sık Sorulan Sorular

Verilerim nerede saklanıyor?
Tüm veriler programın bulunduğu klasördeki database.db dosyasında yerel olarak saklanır. Program bulut tabanlı değildir, bu sayede internet bağlantısı kopsa dahi kesintisiz çalışmaya devam edebilirsiniz.
Eski programdan verileri aktarabilir miyim?
Evet. Bunu admin girişi ile uzaktan bilgisayarınıza bağlanarak "BİZ SAĞLIYORUZ."
Birden fazla bilgisayarda kullanabilir miyim?
Program lisansları tek bir donanım (Makine ID) üzerine tanımlanmaktadır. Ağ üzerinden ortak veritabanı kullanımı veya çoklu bilgisayar kurulumları için lütfen iletişim kanallarımızdan bize ulaşın.
Lisans anahtarını nasıl alabilirim?
Programı açtıktan sonra gri küçük kutuya tıklayarak "Makine Bilgisi"ni kopyalayıp WhatsApp üzerinden Ağahan Bey'e ileterek lisansınızı anında temin edebilirsiniz.
